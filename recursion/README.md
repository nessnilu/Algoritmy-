1. Базовые рекурсивные функции
   **2 вариант:** Реализуйте рекурсивную функцию для вычисления степени числа (power(x, n)).
2. **Алгоритм работы кода на Python:**
   - Проверка на нулевую степень (if n == 0: return 1)
   Если степень равна 0, возвращаем 1, так как любое число в нулевой степени равно 1
   - Обработка отрицательной степени (if n < 0: return 1 / power(x, -n))
   Если степень отрицательная, преобразуем её в положительную и берём обратное значение
   - Рекурсивный случай (return x * power(x, n - 1))
   Умножаем число x на результат вызова функции с уменьшенной на 1 степенью
3. **Временная сложность:** O(n) — линейная сложность
   Объяснение: на каждом шаге рекурсии показатель степени уменьшается на 1, что приводит к n рекурсивным вызовам. Каждый вызов выполняет константное количество операций, поэтому общее время работы пропорционально n.
4. **Чем отличаются перестановки от сочетаний?**
   Перестановки учитывают порядок элементов (ABC ≠ BCA), а сочетания — нет (AB = BA).В перестановках важен каждый вариант расположения, в сочетаниях — только состав.
