2 вариант Жадный алгоритм для составления расписания
Задача: реализовать жадный алгоритм для распределения работ на машины с минимизацией
времени завершения (makespan).
Требования:
- Входные данные: число машин (n) и список длительностей работ
- Выход: распределение работ на машины и максимальное время завершения
- Сравнить с оптимальным решением для малых входов
Входные данные:
Число машин: 3
Длительности работ: [5, 7, 3, 8, 2, 6, 4, 9, 1, 5]
Алгоритм для C++:
1. Использовать cin для ввода количества машин и работ
2. Заполнить вектор длительностей работ
3. Использовать min_element() для поиска машины с минимальной нагрузкой
4. Добавить работу в соответствующее расписание
5. Найти максимальную нагрузку через max_element()
Временная сложность C++: O(n × m)
Для каждой из n работ мы ищем минимум среди m машин
Каждый поиск минимума требует просмотра всех m элементов
Поэтому общее количество операций пропорционально n × m
